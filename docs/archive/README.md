# Archive

Documents and code for things this project no longer has. Kept because the
reasoning in them is often still good, and because a decision that was reversed
is easier to re-open when you can read what it originally said.

**Nothing here is imported, built, or referenced by the running site.** Checked
2026-08-28: no file under `src/`, `e2e/`, `tests/`, `scripts/`, `index.html` or
`vite.config.js` mentions any of it.

- `veneration-glyph-spec.md`, `veneration-glyph.js`,
  `veneration-glyph-proof.html` — the veneration glyph: a small multi-cell mark
  that showed which churches keep a saint, specified in detail and built. The
  author **removed it entirely at Amendment 25** (2026-08-22), and DESIGN.md §2
  records the reversal: the glyph was the one place gold was spent, and taking
  it away is why "gold is drawn nowhere" was true of the site until the die and
  the Today label were given it by instruction. Several sections of HANDOFF.md
  and SESSIONS.md still describe the glyph as though it exists; they say so
  themselves, and they are history rather than the current UI.

If you are reading one of these to bring something back, read the amendment
that removed it first.
